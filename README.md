<h3># Financial Powerbi /h3>

Este projeto descreve a interacao para planejamento e desenvolvimento de um dashboard powerbi,

<h3>## TARGET </h3>

O objetivo deste projeto é fornecer um modelo de Power Bi analise de vendas e relatorio financeiro.

<h3>## BD SQL </h3>

O dashboard responde as perguntas

- Qual o por produto
- Qual a media de preço por produto
- Qual a soma de venda por ano e mes num seguimento
- Qual o total de vendas em unidades e valor
- Qual o lucro por regiao e paises
- Qual a evolucao de lucro por mes do ano
- Qual a soma de vendas por pais
- Qual o total de lucro por seguimento em percentual e moeda
- Deonstrativo interativo de mapa por regiao
